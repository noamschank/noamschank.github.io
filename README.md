# noamschank.github.io

Source of my personal academic website, built with [Quarto](https://quarto.org)
and published with GitHub Pages.

- Edit a page: change the `.qmd` file and push. The site rebuilds itself.
- New note: copy `notes/_template.md` to `notes/<date>-<slug>.qmd`.
- Pages exist in German (root), French (`fr/`) and English (`en/`). Change all three.
- Teaching materials: put the PDF in `materialien/` and link it on the Lehre page.
